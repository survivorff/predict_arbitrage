# 预测市场套利扫描器 · 项目文档

本目录是 **预测市场套利扫描器（Prediction Market Arbitrage Scanner）** 的完整项目文档，涵盖业务背景、架构设计、技术方案、模块详解、API 参考、测试策略、部署运维、迭代计划与变更记录。

> 规格文档（需求 / 设计 / 任务）位于 `.kiro/specs/prediction-market-arbitrage-scanner/`，是本项目的「事实来源（source of truth）」。本 `docs/` 目录是面向开发者与维护者的工程文档，对规格进行展开、补充与延续。

## 项目一句话简介

持续从多个预测市场平台（初期 Polymarket、Kalshi）实时摄取行情，规范化为统一模型，跨平台匹配等价市场，检测计入费用与价差后的套利机会，并通过只读 API 与可配置告警呈现给用户。

## 当前状态

| 项目 | 状态 |
|---|---|
| 阶段 | 第一/二阶段完成；第三阶段（实盘交易）进行中——已完成只读账户/链上余额、模拟盘执行、风控、半自动确认流；真实下单为最后一步 |

| 语言 / 运行时 | Python（开发环境 3.9，目标 3.11+） |
| 测试 | 634 个测试全部通过，离线确定性运行 |
| API | 只读 JSON API + 受鉴权保护的交易 API（FastAPI） |
| 匹配正确性 | 赛段 / 数字阈值 / 结算日期 三重硬 veto（防错配虚假套利，Tier-0 红线） |
| 真实下单 | 尚未启用（需钱包 EIP-712 签名 + 链上资金，最后一个切片） |

## 快速上手

```bash
# 安装依赖
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"

# 运行测试套件
.venv/bin/python -m pytest

# 启动只读 API（默认加载 ./config.yaml）
.venv/bin/python -m uvicorn scanner.app:app
```

详见 [07-部署与运维.md](./07-部署与运维.md)。
